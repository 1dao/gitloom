AUTHENTICATION

          
登录 Gitloom

        

        
      

      
登录后可以查看你有权限访问的私有仓库。密码只用来换取一个 12 小时后自动失效的访问令牌，令牌只存在当前标签页，退出时会立即吊销——密码本身不会被保存。

      
      
      

      

        
        
      

      
还没有账号？

    

  

  
    

      

        

          
CREATE ACCOUNT

          
注册 Gitloom

        

        
      

      

        
创建账号，开始托管代码与协作。

        
        
        
        
        

        

          
          
        

        
已有账号？

      

      

        
账号  已创建成功。

        

          
请保存恢复码。忘记密码时需要用它恢复账号，关闭后无法再次查看。

          
          
        

        

          
        

      

    

  

  
    

      

        

          
NEW REPOSITORY

          
新建仓库

        

        
      

      
仓库建在你自己的账号下，创建后用上面的克隆地址推送即可。默认分支由服务器配置决定，不必在这里选：第一次推送之后 HEAD 会自动指向你实际推上来的那个分支。

      
      
      
      

      

        
        
      

    

  

  
    

      

        

          
DELETE REPOSITORY

          
删除仓库

        

        
      

      
仓库连同全部提交历史会直接从磁盘删除。没有回收站，也没有撤销。确认请输入仓库名 。

      
      

      

        
        
      

    

  

  
    

      

        

          
REPOSITORY SETTINGS

          
编辑仓库

        

        
      

      
修改仓库名称、说明或可见性。设为私有后，只有你、管理员和已授权协作者能看到仓库及其代码。

      
      
改名后旧地址立即失效，已经克隆的本地仓库需要执行 git remote set-url 才能继续推送。

      
      
      

      

        
        
      

    

  

  
    

      

        

          
ACCESS TOKENS

          
访问令牌

        

        
      

      
这个账号当前有效的令牌。令牌本身只在创建时显示一次，这里看不到，也没有任何接口能再取回。吊销后立即失效。

      

      

      

        
      

    

  

  
    

      

        

          
ACCOUNTS

          
账号管理

        

        
      

      
这个实例上的全部账号。新建时服务器会返回一个恢复码，只显示这一次，请当场交给账号本人。删除账号还没有提供——一个账号名下的仓库和它在 Issue 里的署名要先有个去处。

      

      

        
RECOVERY CODE

        
账号  已创建。下面这串恢复码只出现这一次：服务器只保存它的哈希，没有任何接口能再取回它。忘记密码时，这是唯一的回路。
