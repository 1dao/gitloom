AUTHENTICATION

          
登录 Gitloom

        

        
      

      
登录后可以查看你有权限访问的私有仓库。密码只用来换取一个 12 小时后自动失效的访问令牌，令牌只存在当前标签页，退出时会立即吊销——密码本身不会被保存。

      
      
      

      

        
        
      

    

  

  
    

      

        

          
NEW REPOSITORY

          
新建仓库

        

        
      

      
仓库建在你自己的账号下，创建后用上面的克隆地址推送即可。默认分支由服务器配置决定，不必在这里选：第一次推送之后 HEAD 会自动指向你实际推上来的那个分支。

      
      
      
      

      

        
        
      

    

  

  
    

      

        

          
DELETE REPOSITORY

          
删除仓库

        

        
      

      
仓库连同全部提交历史会直接从磁盘删除。没有回收站，也没有撤销。确认请输入仓库名 。

      
      

      

        
        
      

    

  

  
    

      

        

          
REPOSITORY SETTINGS

          
编辑仓库

        

        
      

      
修改仓库说明或可见性。设为私有后，只有你、管理员和已授权协作者能看到仓库及其代码。

      
      
      

      

        
        
      

    

  

  
    

      

        

          
REPOSITORY ACCESS

          
管理协作者

        

        
      

      
给已有账号授予只读或可写权限。协作者可以访问私有仓库；可写协作者还可以推送提交。
